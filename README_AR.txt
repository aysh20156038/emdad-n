============================================================
  مشروع تطبيق أندرويد (APK) — تطبيق "إمداد"
  (نظام منصرف البترول والديزل اليومي — النسخة المعتمدة)
============================================================

• اسم التطبيق: إمداد (Emdad)
• المعرّف (Package ID): com.emdad.fuel
• يدعم: Android 6.0 (API 23) فما فوق حتى Android 14 (API 34)
• المزايا المدمجة للأندرويد:
  1. حفظ دائم للبيانات داخل ذاكرة الهاتف (localStorage).
  2. جسر أندرويد أصلي (AndroidBridge) لحفظ صور التقرير PNG وملفات Excel/CSV مباشرة داخل مجلد Downloads/Emdad.
  3. دعم الطباعة المباشرة وحفظ التقرير كـ PDF بمقاس A4 عبر نظام الطباعة المدمج في أندرويد.
  4. دعم زر الرجوع في الهاتف لإغلاق النوافذ ومنع الخروج المفاجئ.
  5. أيقونات التطبيق الرسمية مجهزة بكافة المقاسات (mdpi حتى xxxhdpi).

------------------------------------------------------------
الطريقة الأولى (الأسرع — بدون كمبيوتر عبر GitHub مجاناً):
------------------------------------------------------------
1. أنشئ مستودعاً (Repository) جديداً على موقع GitHub.com (يمكنك جعله خاصاً Private).
2. فك ضغط هذا الملف وارفع كافة محتوياته (بما في ذلك مجلد .github) إلى المستودع.
3. ادخل إلى تبويب Actions في المستودع واضغط على "Build Emdad Android APK" ثم "Run workflow".
4. خلال ~90 ثانية سيظهر ملف التحميل الجاهز باسم:
   Emdad-Android-APK (وبداخله Emdad-v1.0.apk).
5. حمّل ملف APK وثبّته مباشرة على هاتفك الأندرويد.

------------------------------------------------------------
الطريقة الثانية (على الكمبيوتر عبر Android Studio):
------------------------------------------------------------
1. فك ضغط هذا الملف.
2. افتح برنامج Android Studio واختر Open ثم اختر المجلد المفكوك.
3. انتظر انتهاء مزامنة Gradle ثم اختر من القائمة العلوية:
   Build > Build Bundle(s) / APK(s) > Build APK(s)
4. ستجد ملف APK الجاهز في المسار:
   app/build/outputs/apk/debug/app-debug.apk

------------------------------------------------------------
لتغيير أيقونة التطبيق بصورة أخرى (اختياري):
------------------------------------------------------------
يمكنك استبدال الصور الموجودة داخل مجلدات:
app/src/main/res/mipmap-*/ic_launcher.png
أو من داخل Android Studio عبر:
File > New > Image Asset
